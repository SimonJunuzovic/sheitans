# Sheitans

Coming-soon site for Sheitans. Tame your inner demons.

Static HTML, CSS and JavaScript, served by GitHub Pages at sheitans.com.

Run locally with `python3 -m http.server 8000` and open http://localhost:8000.

See `CLAUDE.md` for structure, brand rules and the to-do list.

The display font (assets/fonts/Sheitans.ttf) is Pirata One by Rodrigo Fuenzalida and Nicolas Massi, licensed under the SIL Open Font License 1.1 (assets/fonts/OFL.txt).
